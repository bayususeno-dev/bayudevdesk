BayuDevDesk

Personal developer workspace & learning guide.

BayuDevDesk adalah website pribadi yang dibuat untuk mendokumentasikan perjalanan belajar web development dan menjadi panduan pengingat dari proses membuat website dari awal hingga dapat diakses secara online.

🎯 Tujuan
Mendokumentasikan hal-hal yang telah dipelajari
Menjadi panduan pribadi ketika lupa suatu langkah
Mencatat workflow development dari awal hingga deployment
Mengembangkan project secara bertahap seiring bertambahnya kemampuan
🛠️ Technologies
Next.js
React
TypeScript
Tailwind CSS
Git
GitHub
